## Problem Statement
Current cyclone-risk assessments often evaluate exposed infrastructure assets individually, while critical infrastructure operates as an interconnected system. Failure of one asset can trigger cascading impacts across electricity, transportation, healthcare and emergency shelter networks. A localized hazard can therefore create a much larger community-level disruption than the initial physical damage suggests.

## Proposed Solution
Cyclone Impact Graph is a geospatial cascading-impact forecasting and decision-support platform. It combines cyclone hazard information, environmental/geospatial data and infrastructure dependency relationships. Critical infrastructure is represented as a graph. Users can simulate an asset failure, trace downstream consequences and view a prioritized intervention list.

## Core Innovation
The project shifts the analysis from isolated asset vulnerability to interconnected system vulnerability.

## Core Workflow
Cyclone → Hazard → Exposure → Dependency Graph → Failure Simulation → Cascading Impact → Priority Intervention

## Prototype
The MVP includes:
1. Interactive map
2. Cyclone scenario layer
3. Critical infrastructure markers
4. Asset risk scores
5. Dependency graph
6. Failure simulation
7. Cascade impact list
8. Priority intervention table
9. Explainability panel

## Technology
Frontend: HTML/CSS/JavaScript, Leaflet
Backend: Python standard-library server
Geospatial direction: Google Earth Engine / GeoJSON
Graph direction: NetworkX-compatible graph model
AI direction: Gemini multimodal explanation layer
Deployment direction: Google Cloud / static hosting

## AI Role
AI is not used as a replacement for the core graph calculation. The intended role is contextual explanation and multimodal reasoning over the calculated scenario and relevant environmental information.

## Data Integrity
The current MVP uses illustrative simulation data. It does not represent an operational emergency forecast. Real deployment would require authoritative infrastructure datasets, validated hazard models, calibration, uncertainty analysis and emergency-management review.

## Expected Impact
The system is intended to support pre-landfall identification of critical dependencies, infrastructure inspection priorities, emergency-access concerns and potential cascading disruption.
